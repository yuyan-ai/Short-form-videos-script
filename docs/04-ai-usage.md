# AI 辅助与个人贡献

项目实际投入时间：3 小时（作者自述）。

## 个人贡献

我主要负责项目框架设计、整体思路，以及实际使用中的个人验证。代码实现、测试和文档整理过程中使用了 AI 辅助。

这里不将 AI 生成的代码计为本人独立手写成果。个人验证是实际使用层面的验证；自动化测试和真实模型运行结果另外保存在仓库中。

## AI 使用范围

- 辅助编写 LangGraph 决策循环、模型接口、三个业务工具和配置读取。
- 辅助编写 Mock、合成素材、品牌规则、测试和本地 Web 界面。
- 根据检查结果辅助修复引用对应、时长估算、改稿后报告失效和原创文案审核问题。
- 辅助整理 README、方案、评估和验收材料。

素材为合成资料，不包含真实产品事实。真实模型记录与 Mock 记录按 mode 区分，Mock 不作为模型能力证明。
